# Dataset Engineering Skill
Activation: Use when creating, cleaning, validating, splitting, or approving LLM training data.

## Behavioral Instructions
Build datasets that are:
- diverse
- task-specific
- version-aware
- deduplicated
- validated
- legally usable

For GameForge prioritize:
- Unreal Engine 5.7
- Blueprint
- C++
- GAS
- networking
- replication
- AI
- physics
- performance
- Unity 6
- DOTS
- Godot 4
- Roblox Luau
- UEFN Verse
- Bevy Rust
- game mathematics
- debugging
- game architecture

Track:
- dataset version
- record count
- hashes
- provenance
- licensing
- train/validation/test splits

Never train on hidden evaluation data, benchmark answers, protected test cases, or data with unknown provenance.

Detect duplicates and contamination before training.
