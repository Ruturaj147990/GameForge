This implementation provides a PickupCollectionComponent that can be attached to an entity. When the player overlaps with an item, the CollectItem function is called, which checks if the item has already been collected and updates the inventory accordingly.

Note: This code assumes that the `Entity` class has a method to add components and retrieve them by type index. The `InventoryComponent` class is responsible for updating the inventory logic. The `Item` class is a base class for items in the game, and its implementation is not provided here.
