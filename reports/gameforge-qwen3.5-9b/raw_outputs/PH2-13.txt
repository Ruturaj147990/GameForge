Here is a production-ready, decoupled state machine implementation for Unreal Engine 5.7.4. This design utilizes the Enhanced Input system principles (decoupled logic), proper memory management via `TSubclassOf`, and safe transition guards.

### Design Overview
1.  **`ICharacterState`**: An interface defining the lifecycle (`Enter`, `Update`, `Exit`).
2.  **`CharacterStateManager`**: A `UObject` that holds the current state instance and handles transitions. It uses `TSubclassOf` to allow runtime polymorphism without casting.
3.  **Safety**: Transitions are guarded by checking if the target state is valid and ensuring the current state is properly exited before entering a new one.

### Implementation Files

	UFUNCTION(BlueprintImplementableEvent, Category = "State")
	virtual void Exit(UCharacterStateManager* Owner) {}
