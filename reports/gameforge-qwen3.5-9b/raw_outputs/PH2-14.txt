Here is the production-ready implementation of a high-performance, networked Inventory System for Unreal Engine 5.7.

This solution utilizes **`FFastArraySerializer`** and **`FFastArraySerializerItem`** to minimize bandwidth usage during replication. It leverages **`UObject::IsGarbage`** checks to avoid replicating deleted items and uses **`FFastArraySerializer::AddItem`** with a custom item struct to handle delta updates efficiently.

### Architecture Overview

1.  **`FInventoryItem`**: A lightweight `struct` containing only replicated data (no `UObject` pointers). This is crucial for `FFastArraySerializer` to work efficiently.
2.  **`AInventory`**: The actor holding the inventory. It overrides `ReplicateData` to handle the serialization logic.
3.  **`FFastArraySerializerItem`**: A custom struct defining how a single item is serialized (Delta mode).
4.  **`FFastArraySerializer`**: The engine's built-in serializer used to generate the delta payload.
